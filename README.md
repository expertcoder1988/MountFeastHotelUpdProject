# Mount Feast Hotel - Updated MVC Web Platform

Updated ASP.NET MVC web platform for **Mount Feast Hotel**, including booking-oriented guest pages and administrative management.

## Overview
Iteration of the Mount Feast hotel web product with room presentation, reservation flows, and back-office management screens.

## Key Features
- Public hotel website experience
- Room categories, gallery, and content pages
- Booking / reservation workflows
- Admin management for property operations
- SQL Server + MVC architecture

## Tech Stack
- **Backend:** ASP.NET MVC (C#)
- **Frontend:** Razor, JavaScript, jQuery, Bootstrap
- **Database:** Microsoft SQL Server
- **Solution:** `MountFeastMVC.sln`
- **App folder:** `MountFeastMVC/`

## Getting Started
1. Open `MountFeastMVC.sln`
2. Configure connection strings
3. Restore NuGet packages
4. Build and run
